# 第 1 章　認識全國科展：我們要走的路

> 現行上課節奏是 **第 1–3 週濃縮課**（本章併入濃縮第 1 週）。本章是分章詳解，給課後補讀、補課或卡關時查。

**對應**：分章詳解（原第 1 週節奏）  
**一句話目標**：讓學生知道科展是「用科學方法回答一個可檢驗的問題」，而且全國評審會用同一套標準看作品。

---

## 1-1　本週學習目標

上完本週，學生能夠：

1. 說出台灣科展的三級賽制（學校 → 地方 → 全國）。
2. 說出國中組有哪些科別，並舉例什麼題目可能落在哪一科。
3. 用自己的話解釋全國科展四大評審面向。
4. 分辨「科學研究」與「科學展示／科學遊戲／科學報告抄寫」。
5. 啟用研究日誌，寫下第一頁的課程契約。

**對齊評審**：展示及表達（獨立度、全組貢獻）；研究主題（可用科學方法檢驗）。

## 1-3　核心講義

### （一）科展在比什麼？

科學展覽不是：

- 把課本實驗再做一次、拍照貼海報
- 做一個很酷的裝置卻說不出「我在回答什麼問題」
- 蒐集很多資料寫成報告，但沒有自己的證據
- 家長或補習班代做，學生只負責背稿

科學展覽是：

> 針對一個**夠小、夠清楚、測得到**的問題，用**可重複的方法**收集證據，再根據證據做出**有限制的結論**，並能向別人說明。

這和 108 課綱自然科學的探究歷程一致：發現問題 → 規劃與研究 → 論證與建模 → 表達與分享。科展是這條路走得比較深、比較長的版本。

### （二）台灣的賽制：你要先贏自己學校，才有機會到全國

依據《中華民國中小學科學展覽會實施要點》：

```
學校科展  →  縣市／直轄市地方科展  →  全國中小學科學展覽會
（約 4 月底前）    （約 5 月底前）              （約 7 月底前）
```

重點提醒（跟學生說明白）：

- **全國不是報名就能去**，必須經地方科展選拔。
- 全國國中組與國小組件數，大致依各縣市學生人數比例分配，名額非常有限。
- 全國優勝還可能銜接臺灣國際科學展覽會，甚至國際賽。本社團以「全國科展水準」為訓練標竿，但本學期期末先完成「有全國骨架的作品」。

### （三）國中組科別（選題時就要想「我要站在哪一科被評」）

國中組目前分為 8 科：

1. 數學科
2. 物理科
3. 化學科
4. 生物科
5. 地球科學科
6. 生活與應用科學科（一）：機械／能源／光電／物理／資訊之工程與應用
7. 生活與應用科學科（二）：生物科技／食品科學
8. 生活與應用科學科（三）：化學工程／環境科學

**選科原則（給學生的口訣）**：

- 你的**核心方法**是什麼，就進哪一科。  
  例如：做淨水濾材，若重點是「吸附機制的化學定量」偏化學或應科（三）；若重點是「濾芯結構與流量工程」偏應科（一）。
- 不要為了「比較好獎」而硬套科別。評審一眼就看出方法與科別不合。
- 生活應用科仍必須有科學方法，不是「做一個有用的東西」就夠。

### （四）全國評審四大面向（本社團的北極星）

以下摘自實施要點之評審標準，改寫成學生能用的句子。

#### 面向 A｜研究主題

官方要點：清楚且聚焦；對領域有貢獻；可用科學方法檢驗；有鄉土相關性更佳。

學生版：

- 別人聽完 20 秒，知道你在研究什麼。
- 你的問題可以用實驗、觀察、測量或數學來回答，不是靠投票或感覺。
- 最好跟校園、社區、在地產業、在地自然有關，但「鄉土」不是必勝咒，仍要科學。

#### 面向 B｜創意、學術或實用價值

官方要點：有原創性，方法可行；對科學、社會或經濟有影響潛力。

學生版：

- 不是沒人做過才叫原創；**在前人基礎上提出新變因、新測量、新解釋**也是原創。
- 方法要國中生做得到、學校做得到、安全做得到。
- 「可能有用」必須建立在證據上，不能只喊口號。

#### 面向 C｜科學方法之適切性（全國最常在這裡分勝負）

官方要點：計畫周全；控因與變因清楚完整；系統蒐集與分析；結果可再現；適當用數學／統計；數據足以證實結論。

學生版：

- 一次主要只改一件事，其他條件要鎖住。
- 同一條件至少重複多次，別人照做也應得到相近趨勢。
- 結論只能講到數據能講的範圍，不可以腦補。

#### 面向 D｜展示及表達能力

官方要點：海報有邏輯與圖表；備研究日誌與文獻；口試清楚；懂原理與限制；獨立執行；全組都懂；有下一步。

學生版：

- 日誌是「你真的做過」的證據，評審會翻。
- 組員不能只有一個人會講。
- 被問「限制是什麼」要答得出來，這是加分不是丟臉。

### （五）歷屆評審常提醒國中組的弱點（提早打預防針）

整理自近年全國科展分科總評語的共同方向：

| 常見弱點 | 全國評審會怎麼看 | 本課程何時練 |
| --- | --- | --- |
| 題目太大、實驗一堆但互不連貫 | 主題不聚焦 | 第 2、8、9 週 |
| 沒查歷屆作品，做成「重複題」 | 原創性不足、文獻不足 | 第 6 週 |
| 變因沒控制好 | 方法不適切 | 第 3 週 |
| 只有一次數據、沒有重複 | 不可再現 | 第 4、7、8 週 |
| 圖表漂亮但沒有分析 | 數據不足以支撐結論 | 第 7 週 |
| 日誌事後補寫、太乾淨 | 獨立度與真實性受質疑 | 第 5 週起每週抽查 |
| 口試只背稿，問原理就卡住 | 表達與理解不足 | 每週 5 分鐘發表 |

### （六）作品最後會長什麼樣子（先有地圖，免得做到後面才慌）

一件完整科展作品，通常有四件套：

1. **作品說明書**（A4，總頁數 30 頁以內，不含封面封底目錄；摘要 300 字以內；封面不寫校名與姓名）
2. **研究日誌／實驗紀錄本**（成冊裝訂，手寫為主，帶到評審現場）
3. **海報（作品說明板）**（全國為「ㄇ」型板；本學期社團可用海報紙或簡報代替）
4. **口頭說明與問答**（全體作者都要能講）

說明書常見骨架（全國附件範例）：

```
摘要（300 字以內）
壹、前言（研究動機、目的、文獻回顧）
貳、研究設備及器材
參、研究過程或方法
肆、研究結果
伍、討論
陸、結論
柒、參考文獻資料
```

第 1 週不必會寫，但要知道：**你現在學的每一項技能，最後都會變成說明書裡的某一章。**

## 1-4　課堂活動

### 活動一：評審翻譯官（30 分鐘）

將全班分成 4 組，每組領一個面向（A–D）。任務：

1. 把官方句子改寫成 3 句「如果我是評審，我會問……」
2. 再寫 3 句「如果我是作者，我會準備……」
3. 全班匯整成「社團評審檢核卡」（貼教室，用到第 17 週）

教師提示（參考答案）：

- 面向 C 可能問：「你怎麼證明這不是巧合？重複幾次？控制了哪些條件？」
- 面向 D 可能問：「這張圖的橫軸是什麼？為什麼選折線圖不是長條圖？」

### 活動二：這算不算研究？（30 分鐘）

教師口述或投影三則「假想作品」，請學生用四面向快速貼貼紙：綠＝像全國作品，黃＝有潛力但缺一塊，紅＝還不是研究。

**案例 1**：我們做了火山爆發模型，用蘇打粉和醋，很好看，全班都很喜歡。  
→ 紅。這是科學遊戲／展示，沒有可檢驗問題與系統數據。

**案例 2**：我們測量校園 5 個地點的土壤 pH，各重複 3 次，畫圖比較，並查地質資料解釋為何運動場旁偏鹼。  
→ 黃到綠。有測量、重複、解釋；若能提出「為什麼」的機制假設並再設計實驗，更接近全國。

**案例 3**：我們改良紙吸管防水時間。查了 3 件歷屆科展與 2 篇網路文章，固定水量與角度，只改塗層種類，每種測 10 次，計算平均與全距，討論失敗的吸管。  
→ 綠的骨架。有文獻、單一變因、重複、不確定性、限制。

## 1-5　研究日誌第一頁（當堂完成）

請學生在日誌封面內頁寫：

```
研究日誌使用契約
1. 每次上課或做實驗當天寫，不事後一次補完。
2. 用筆書寫。寫錯請劃一條線，旁註日期與原因，不撕頁、不塗黑。
3. 記錄日期、參與者、做了什麼、看到什麼、下一步。
4. 原始數據寫在日誌裡，之後才謄到電腦。
5. 這是給評審看的「誠實證據」，不是美工簿。

姓名：__________  組別：（第 9 週再填）
開始日期：__________
```

教師當堂抽 3 本看是否寫完契約。

1. 進入臺灣網路科教館：<https://www.ntsec.edu.tw/>

## 1-8　常見迷思

| 迷思 | 澄清 |
| --- | --- |
| 要有大學實驗室才進得了全國 | 許多國中優勝來自生活題材＋嚴謹方法。儀器高級不是評審第一名條件。 |
| 題目愈大愈厲害 | 相反。全國要「清楚且聚焦」。 |
| 海報漂亮就會赢 | 海報只是表達。方法與數據才是主菜。 |
| 我現在沒題目很正常嗎 | 正常。現行課表第 1–3 週濃縮練功，第 3 週末交候選、第 4 週定題。 |
