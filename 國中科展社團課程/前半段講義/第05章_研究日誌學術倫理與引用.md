# 第 5 章　研究日誌、學術倫理與文獻引用：讓評審相信這是你做的

> 現行上課節奏是 **第 1–3 週濃縮課**（本章併入濃縮第 2 週）。本章是分章詳解，給課後補讀、補課或卡關時查。

**對應**：分章詳解（原第 5 週節奏）  
**一句話目標**：把「誠實的過程證據」練成肌肉記憶，並學會不抄襲、會引用。

---

## 5-1　本週學習目標

上完本週，學生能夠：

1. 依全國科展規格說明研究日誌該長什麼樣子。
2. 寫出一則合格的當日實驗紀錄（含失敗）。
3. 分辨抄襲、改寫不足、正確引用。
4. 用簡化 APA 格式寫出書、網頁、科展作品三種參考文獻。
5. 說出指導老師可以幫什麼、不可以代做什麼。

**對齊評審**：備實驗紀錄簿及參考文獻；處理與執行之獨立度；真實性與研究倫理。

## 5-3　核心講義

### （一）研究日誌不是週記，是原始證據

實施要點明文：

> 參展作品之研究日誌或實驗觀察原始紀錄本（須記錄於騎馬釘或線膠裝訂成冊筆記本）應攜往評審會場供評審委員審閱。

也就是說：

- 要**成冊**，不要活頁、不要一堆影印夾
- 要能帶到現場，不要只靠說明書裡的漂亮表
- 科教館不收日誌代轉；你自己帶

評審翻日誌時在看：

1. 日期是否連續、是否像真正做過
2. 原始數據是否先出現在日誌、再出現在說明書
3. 失敗、意外、改方法有沒有寫（太完美反而可疑）
4. 字跡與內容是否像學生、是否全組都有參與痕跡

### （二）合格日誌清單（請貼在筆記本封面內）

**格式**

- [ ] 線膠裝或騎馬釘，有連續頁碼
- [ ] 不撕頁、不塗黑；寫錯劃線並簽名註日期
- [ ] 主要用手寫；照片可貼但需標日期與圖說
- [ ] 電腦檔是整理檔，不是唯一檔

**每次必寫**

- [ ] 日期、開始與結束時間、地點、出席者
- [ ] 今天目的（一句）
- [ ] 材料與條件（溫度、濃度、版本號）
- [ ] 步驟（可寫「同 p.12 步驟，今日改了……」）
- [ ] 原始數據（表格）與現象
- [ ] 異常與可能原因
- [ ] 下一步

**禁止**

- 比賽前一週用同一支新筆補寫整本
- 只貼說明書打字稿
- 塗改液把錯的數據蓋掉
- 把「不理想」的頁撕掉

### （三）示範：一頁好紀錄（教師可板書）

```
2026-10-07  15:10–16:50  理化教室  出席：林○、陳○
目的：比較翼長 6 cm 與 8 cm 紙直升機的滯空時間

條件：A4 70 磅影印紙、迴紋針 1 個固定於腳、
      釋放高度 2.0 m（以尺在門框標記）、室內無風扇

數據：滯空時間（s）  碼錶：陳○  釋放：林○

翼長 6 cm：1.12, 1.08, 0.41(撞桌,作廢), 1.15, 1.09, 1.11, 1.07, 1.14
翼長 8 cm：1.33, 1.29, 1.31, 1.40, 1.28, 1.35, 1.30, 1.32

現象：8 cm 旋轉較慢但落地較穩。第 3 次 6 cm 被風（走廊開門）吹偏。

問題：碼錶反應時間可能偏慢 → 下週改用手機 240fps 逐格。

下一步：固定開門、改影片計時；再加 10 cm 翼長。
```

請指出好在哪：有作廢理由、有分工、有條件、有下一步。不是作文比賽。

### （四）學術倫理：全國從 111 年起就在比對作品

科教館公開說明：地方與全國會做作品比對，並擴及歷屆科展、論文與其他競賽。查獲抄襲、仿製、同一作品換作者、他人代做，可撤銷資格、追回獎勵、停止參展 1–3 年。

**學生必須記住的四條紅線**

1. 不可以把別人的說明書改幾個字當成自己的。
2. 不可以用家長、補習班、學長的成品假冒。
3. 延續自己以前的題目可以，但必須誠實寫「新增了什麼」，並填延續性研究相關表件（正式參賽時）。
4. 生成式 AI 可以幫忙想測量方法、檢查句子通順，**不可以**替你寫研究動機、捏造文獻、或產生假數據。使用時在日誌註明「今日使用 AI 討論了……」。

**引用不是可選配，是把功勞還給前人。** 全國要原創，不是要你假裝世界從你開始。

### （五）抄襲、改寫、引用（當堂必須練）

原文（假設）：「控制變因是指實驗中除操作變因外，其餘保持不變的條件。」

| 類型 | 例子 | 判定 |
| --- | --- | --- |
| 抄襲 | 整句搬進說明書，不註來源 | 違規 |
| 假改寫 | 「控制變因就是除了操作變因，其他都保持不變的條件。」仍不註來源 | 仍是抄襲 |
| 正確引用後改寫 | 實驗要能比較，必須把其他可能影響結果的條件固定下來，只留下要探討的那一個因素（翰林雲端學院，n.d.）。 | 可接受 |
| 直接引句 | 加上引號與來源，且不可整段都是引句 | 可用，但科展應以自己的話為主 |

國中實務：文獻回顧用「某人做了什麼、結果如何、留下什麼缺口」，結尾接「因此本研究要……」。

### （六）簡化 APA（夠國中社團使用）

正式比賽請跟當年實施要點「最新 APA」。本課程先練三種最常用：

**1. 科展作品（網路科教館）**

作者.（屆別年份）. 作品名稱. 中華民國第○屆中小學科學展覽會國中組○科.  
https://……

國中作品說明書常匿名，若頁面看得到學校與作者就照寫；若只有作品名，用作品名當標題，並註「國中組某科優勝作品」。

**2. 書籍**

作者.（年份）. 書名. 出版者.

例：梅期光（2015）. 認識科展的第一本書：科展完全攻略. 五南.

**3. 網頁**

作者或單位.（年份或 n.d.）. 標題. 網站名. 網址

例：國立臺灣科學教育館.（n.d.）. 實施要點. https://twsf.ntsec.gov.tw/

文中引用：第一次出現寫（作者，年份）。沒有作者就寫單位。

### （七）獨立度：老師與家長的邊界

評審會問：「這是誰做的？」實施要點：作品應由學生親自研究製作，未實際參加者不得掛名；教師不得代做。

| 可以 | 不可以 |
| --- | --- |
| 問關鍵問題、教技術、示範儀器、提醒安全 | 替學生決定所有題目與結論 |
| 幫忙買不到的材料、開實驗室 | 家長在家做好數據或海報交來 |
| 改文法與結構建議 | 教師重寫說明書到評審認不出學生 |
| 陪同野外但學生記錄 | 掛名沒做事的同學 |

團體作品：全國規定國中最多 3 人，且**所有作者都要理解並有貢獻**。第 9 週分組時就要寫分工表。

## 5-4　課堂活動

### 活動一：把舊數據寫成正式頁（30 分鐘）

用第 4 週測量擂臺的數字，當堂寫一頁「補示範」。注意：這是教學例外。教師要講：

> 真實研究禁止事後補造。今天是練習格式；從今天起，新的數據必須當天寫。

同儕用合格清單互打勾。教師收 4 本當眾念「好的異常紀錄」。

### 活動二：抄襲法庭（30 分鐘）

發 4 張卡片（原文＋學生段落），小組判決：無罪／改寫不足／抄襲，並改成正確版本。

建議卡片主題可用第 3 章三變因定義、第 1 章評審標準改寫。避免用真的得獎說明書整段，以免學生以後誤用。

### 活動三：師生分工契約（15 分鐘）

全班共同完成後貼牆：

```
老師承諾：……
學生承諾：……
家長可以：……
掛名規則：沒做實驗、沒寫日誌、不能講原理的人，不掛名。
```

## 5-7　常見迷思

| 迷思 | 澄清 |
| --- | --- |
| 日誌要像美術作業 | 清楚、真實優先。可以整齊，但不要為了整齊重抄而失去原始性。 |
| 引用太多顯得我不原創 | 相反，全國優勝通常文獻比較夠，才能指出缺口。 |
| 用 AI 寫會比較像全國作品 | 評審問答會穿幫；且有捏造文獻風險。 |
| 失敗實驗不要留 | 失敗是討論章的黃金材料。 |
