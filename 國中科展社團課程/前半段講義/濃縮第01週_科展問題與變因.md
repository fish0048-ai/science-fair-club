# 第 1 週　科展、好問題與三變因

**上課時數**：2 小時  
**一句話目標**：全班用同一套課堂例題，對齊**全國能上場的問題與設計規格**，並認識本社團路徑：**發想 → 模擬找模型 → 實驗驗證 → 結論**。

## 1-1　本週學習目標

上完本週，學生能夠：

1. 用評審四面向當**檢核句**評論一則案例，並依**核心方法**判斷可能科別。
2. 分辨觀察、推論、問題、假設、目的；寫出「若 IV，則 DV，因為（機制）」且能被數據打槍的假設。
3. 把大而空的題收成「在（條件）下，（IV）如何影響（可測 DV）」；分辨機制型／比較型／設計型。
4. 為應變項寫**操作性定義**（量什麼、用什麼、怎麼量、量幾次）；標出操作／應變／至少 6 個控制變因（六類想一遍）；指出一個**混淆變因**；說出對照基準。
5. 啟用成冊研究日誌，寫下第一頁契約。  
6. 能用自己的話複述本社團四段路徑（發想→模擬找模型→真實實驗驗證→結論）。

**本週對齊規則**：已有甄選稿、已得過獎，也要做完同一張學習單與同一場示範。詞彙超前不能跳關。過關不是「會背四面向」，是設計經得起評審問。

**對齊評審**：研究主題（清楚、聚焦、可檢驗）；科學方法（變因完整、計畫周全）。

## 1-3　核心講義

### （一）全國在比什麼

科學展覽**不是**：課本實驗重做貼海報、很酷但說不出問題的裝置、只查資料沒有自己的證據、家長代做學生背稿。

科學展覽**是**：針對一個夠小、夠清楚、**測得到**的問題，用可重複的方法收集證據，再做出**有限制**的結論，並能說明機制與缺口。

這和 108 課綱探究歷程一致：發現問題 → 規劃與研究 → 論證與建模 → 表達與分享。科展是這條路走得比較深、比較長的版本。

**本社團怎麼走這條路（第 3 週會用紙直升機走一小輪；後期用自己的題）**

```
發想（可檢驗問題、一次只改一件事）
    → 電腦／試算表模擬，找出模型、寫死預測
    → 真實實驗，用同一套 IV／DV 驗證
    → 結論：模型相符、部分相符、或被打槍，並寫限制
```

先模擬再實驗，是為了讓「預測」出現在收數據之前，評審才問得動「你實驗前認為會怎樣」。細節見附錄 G。本週先會講；第 3 週才做迷你一輪。

台灣賽制：學校 → 地方（縣市）→ 全國。全國不是報名就能去；名額依縣市學生數比例，極少。國中組每件最多 **3 名**作者，都要能講。全國優勝才可能銜接國際賽；本學期先練出「有全國骨架」的作品。

**國中組八科**（選科看**核心方法**，不要猜哪科比較好獎）

| 科 | 核心方法大致落在 |
| --- | --- |
| 數學、物理、化學、生物、地球科學 | 該領域的證明、測量、機制 |
| 生活與應用科學（一） | 機械／能源／光電／資訊工程 |
| 生活與應用科學（二） | 生物科技／食品 |
| 生活與應用科學（三） | 化工／環境 |  

例：淨水濾材若重點是吸附的化學定量 → 化學或應科（三）；若重點是濾芯結構與流量 → 應科（一）。方法與科別不合，評審一眼看出。

**評審四面向（當檢核句用，不是背完就過）**

| 面向 | 評審問你的句 |
| --- | --- |
| 研究主題 | 20 秒聽得懂你在測什麼？能用實驗／測量／數學回答嗎？ |
| 創意、學術或實用價值 | 比最像的前人多問了哪一點（新變因、新指標、新條件、新解釋）？「有用」有沒有數據？ |
| 科學方法 | 一次改幾件事？控制寫全了嗎？n 夠嗎？別人照做趨勢會像嗎？結論有沒有超過數據？ |
| 展示及表達 | 圖有軸標嗎？日誌是當天寫的嗎？全組都懂限制嗎？ |

全國最常在**科學方法**分勝負。專有名詞密度不能補方法漏洞。

把官樣條文翻成學生句。**先自己寫一句，再對表。**

| 實施要點常見用語 | 學生版：過關時你要能答 |
| --- | --- |
| 研究主題清楚、聚焦 | 我只追一個問題；20 秒講完「改什麼、量什麼」 |

### （一Ｃ）三則病例（當堂討論，不准改成自己的稿）

| 病例 | 像不像研究 | 四面向哪一面先倒 |
| --- | --- | --- |
| A. 火山模型：很像、會冒煙，說不出要測什麼 | 不是研究，是展示 | 研究主題 |
| B. 只查「時間旅行可不可能」的文獻報告，沒有自己的測量 | 不是研究，是讀書心得 | 科學方法 |
| C. 方法看起來很全國，但一次改車身形狀又改輪子重量 | 研究骨架有，方法不及格 | 科學方法（混淆） |

口頭練習：對 C 說出一句評審會問的話。標準方向：「你怎麼知道比較快是因為形狀，不是因為比較重？」

### （二）從觀察到可被打槍的假設

探究會來回改，但說明書必須讓別人跟得上：

```
觀察 → 問題 → 文獻與假設 → 設計並收集數據 → 分析 → 結論與限制 → 新問題
```

| 探究步驟 | 以後說明書通常寫在 |
| --- | --- |
| 我為什麼在意 | 前言／研究動機 |
| 我要回答什麼 | 研究目的 |
| 別人做過什麼、我的缺口 | 文獻回顧 |
| 我猜會怎樣 | 假設 |
| 我怎麼測 | 器材與方法 |
| 我看到什麼（事實） | 結果 |
| 這代表什麼（解釋） | 討論 |
| 我現在能說什麼、不能說什麼 | 結論 |

**關鍵紀律（本週先記，第 3 週會練）**：結果章只寫數據顯示什麼；機制與文獻比較放到討論。

| 詞 | 意思 | 例子 |
| --- | --- | --- |
| 觀察 | 五官或儀器的事實 | 3 分鐘後杯底仍有固體 |
| 推論 | 用知識解釋觀察，可能錯 | 可能已飽和 |
| 問題 | 要追究、最好能測 | 水溫如何影響蔗糖溶解度？ |
| 假設 | 暫時答案，必須能被數據打槍 | 水量與攪拌固定時，水溫從 20°C 升到 60°C，100 mL 水能溶解的蔗糖質量會增加，因為溫度升高通常提高溶解度 |

口訣：**觀察是看到的，推論是想到的，問題是要查的，假設是敢被打臉的。**

| 容易混的三句 | 本課程規定 |
| --- | --- |
| 目的 | 我要找出什麼關係（不問對錯） |
| 假設 | 我預測關係長怎樣、為什麼（能被打槍） |
| 預測 | 若假設對，數據會長怎樣（可寫在假設後面） |

假設公式（本週過關規格）：

> 若 **（操作變因＋水平）** 改變，則 **（應變變因＋單位）** 會 **（升／降／不變）**，因為 **（一句機制）**。

弱：「溫度跟溶解有關。」  
仍弱：「水溫愈高溶解愈多。」（沒水平、沒單位、沒機制）  
強：「水量與攪拌固定時，水溫從 20°C 升到 60°C，蔗糖溶解度（g／100 mL）會增加，因為溫度升高通常提高固體溶解度。」

**打槍練習**：怎樣的數據會讓上面這則假設失敗？  
答：若 20°C 與 60°C 的溶解度幾乎相同，或 60°C 反而較低（在控制住水量與攪拌的前提下），假設就不被支持。被推翻仍是好科學。

**好問題五條件**（少一個，後期通常會爆）

1. **可檢驗**：能用實驗、調查、測量或數學得到證據。×外星人　○頂樓與一樓紫外線強度差  
2. **可測量**：應變項有單位、工具、手續。×植物比較開心　○綠豆 7 日苗高平均（cm）  
3. **單一聚焦**：一段時間只追一個核心問題。×同時測保溫＋通風＋排水＋做成產品  
4. **安全可行**：時間、器材、倫理、國中社團做得到。  
5. **有新意空間**：新意＝方法／指標／條件／解釋至少改一項，不是換標題。×驗證光合作用需要光　○遮光程度與澱粉顯色面積的定量關係  

本週課堂弱題（全班同一道，不准改成自己的稿）：

> 弱：「哪個車身比較流線、比較快？」  
> 過關改寫必須有：單一操作變因、有單位的應變項、至少一個控制、一句機制、承認若用滑行距離則它只是**代理變因**（還有輪阻）。

過關改寫示例（不是唯一答案，用來對規格）：

> 在同一斜坡、同一輪子與同一釋放高度下，車頭截面形狀（方形／圓弧）如何影響滑行 1.50 m 的平均時間（s）？  
> 假設：截面改為圓弧時平均時間會變短，因為空氣阻力較小。若只用滑行距離當指標，它只是速度的代理，還受輪阻影響。

看起來很厲害、其實測不到的題（只查相對論、一次證明熵定律、同時測很多件事）第 4 週會擋。本週先把課堂例題改到過關規格。

### （三）一次只改一件事、寫死怎麼量

實驗要回答的是：**是不是因為 A，所以 B 改變？** 需要：主動改 A、測量 B、鎖住其他、有比較基準、重複多次。

| 本課程用詞 | 也稱 | 意義 |
| --- | --- | --- |
| 操作變因 | 自變項 independent variable | 你故意改的那一件；前期主實驗一次只改**一個** |
| 應變變因 | 依變項 dependent variable | 用來判斷結果的測量；必須可量化 |
| 控制變因 | 控制變項 controlled variables | 故意保持不變的其他因素；愈容易被忽略愈要寫 |

**混淆變因（confound）**：你沒鎖住、卻也會拉動應變項的東西。同時改層數又換品牌，就不知道差在哪。評審問「會不會其實是××造成的？」答得出來才算過關。

**對照**：比較的基準（沒處理或標準條件）。沒有它，你只有數字，沒有「跟沒處理比差在哪」。微生物「只用我的配方、菌落很少」可能是培養失敗——此處只練邏輯；真正培養未知菌是紅燈。

**操作性定義**（四問都要寫進日誌，本週示範必填）

1. 量什麼　2. 用什麼量　3. 從哪量到哪、讀到幾位　4. 每個條件幾次、什麼算作廢  

弱：紙巾「吸水力比較好」。  
強：同品牌同尺寸，層數 1／2／3；浸泡 30.0 s 後以電子秤測增重（g），讀到 0.01 g；每層 n＝5；紙巾未完全浸入或破掉則作廢重做。無電子秤：垂入水深 1.0 cm 的杯，20.0 s 後量水線爬升高度（mm）。

**重複**：每個條件至少 **5** 次有效（能 8 次更好）。生物材料每個條件至少 10 個個體再取平均。測量順序盡量打亂，避免「先做的都是條件 A、人已經很熟練」。

雙因子（一次看兩個因素）必須做滿所有組合，資料量會爆；前期迷你探究**禁止**。正式題要教師點頭，分析用附錄 E，不要做完兩次 t 檢定就當雙因子。

### （四）把大問題切小、選對問題類型

學生最常犯：問題像百科全書。收斂口訣：**加條件、加對象、加指標。**

**收斂句型**：

> 在 **（條件／地點／材料）** 下，**（操作變因）** 如何影響 **（可測量的應變變因）**？

示範（本週當堂走一遍，不當正式題）：

| 步驟 | 句子 |
| --- | --- |
| 太大 | 空污對身體不好，我們想改善空污。 |
| 加對象 | 本校前門與後門的空氣差在哪？ |
| 加指標 | 若沒有專業儀器，可改「不同口罩材質對麵粉模擬粉塵的阻隔質量差（g）」 |
| 過關規格 | 在固定粉塵量與配戴時間下，口罩層數如何影響濾片增重（g）？ |

**三種全國能打的問題類型**（先有地圖，第 4 週才選自己的）

1. **機制型（為什麼）**：核心是原理。例：為什麼加鹽會改變冰的熔化？要能量化（熔化時間、溫度曲線），不能只拍影片說「比較快」。  
2. **比較型（哪一個、差多少）**：例：三種洗碗精在固定油量下的去油時間。不要做成廣告；控制品牌以外的一切。  
3. **設計型（如何更好）**：例：擋風板如何讓雨衣更穩。必須有量化指標（翻覆次數、阻力、乾燥時間），否則會變成美工發明展。

數學科另有：模式發現、證明、模擬、資料規律。仍需「清楚問題＋可檢查的論證」。

### （五）控制變因六類、病例能不能下結論

寫控制變因不要空想，按六類掃一遍（本週紙巾示範至少每類想一項，總共 ≥6）：

| 類 | 問自己 | 紙巾示範 |
| --- | --- | --- |
| 材料 | 品牌、尺寸、批號有沒有換？ | 同品牌同尺寸 |
| 環境 | 溫濕度、風、光照？ | 室內無風、同桌 |
| 操作 | 誰放手、怎麼放、先後順序？ | 同一人、層數順序打亂 |
| 測量 | 起迄點、讀到幾位、哪個工具？ | 浸泡 30.0 s、秤到 0.01 g |
| 時間 | 等待多久、哪一天做？ | 當堂同一時段 |
| 樣本 | 取哪一塊、要不要丟掉邊緣？ | 不使用已濕或破的紙巾 |

**病例：能不能下結論？**（先獨立判斷，再揭曉）

| 病例 | 能不能下「因為 A 所以 B」 | 為什麼 |
| --- | --- | --- |
| 1. 1 層與 3 層各做 1 次，3 層增重較多 | 不能 | n＝1，碰巧就能贏 |
| 2. 1 層用薄紙巾、3 層用厚紙巾，3 層較多 | 不能 | 同時改層數與品牌＝混淆 |
| 3. 同品牌，1／2／3 層各 5 次，只改層數 | 可以談趨勢 | 仍要寫限制（室溫、放手） |
| 4. 自製洗手乳後培養皿「幾乎沒菌」 | 不能當殺菌證據 | 可能培養失敗；且未知菌是紅燈 |

讓學生體驗：**設計寫在紙上很完美，手上永遠有漏網之魚。** 漏網之魚要寫進控制變因，下一次鎖住。

### （六）60 秒口頭：本週規格怎麼講給評審聽

以後每件作品都要練這四句。本週先用課堂例題講：

1. **問題**：我只改＿＿，量＿＿（單位）。  
2. **方法**：對照是＿＿；我鎖住＿＿、＿＿、＿＿。  
3. **還沒有數據**：所以現在不能下結論；第 3 週才會有迷你探究的圖。  
4. **限制**：若用代理變因，我承認它不是我想量的那件事本身。

抽問進階生：不能用「我甄選表已經寫過了」代替這四句。

## 1-4　課堂活動

本週**短講不超過 15 分鐘**，其餘都要開口或動手。

### 活動一：暖身討論（約 8 分）

一桌 30 秒：全國作品長什麼樣？再加 20 秒：要不要先做實驗再想會怎樣？本社團答案是**先模擬預測再做**。不准講自己的甄選稿。

### 活動二：評審翻譯官（討論＋練習，約 8 分）

把「科學方法之適切性」翻成一句你會問同學的話。同桌交換，對方要能聽懂。

### 活動三：三則病例（討論，約 6 分）

A 火山模型、B 只查時間旅行、C 一次改兩件事。每則先獨立判斷「像不像研究、哪一面先倒」，再揭曉。對 C 說出一句評審會問的話。

### 活動四：弱題改寫（實作，約 12 分）

全班同一道：「哪個車身比較流線、比較快？」寫到學習單。必須有單一 IV、有單位的 DV、控制、機制、代理變因。寫完同桌互改一輪。

### 活動五：好問題診所（練習，約 8 分）

抽 2 題改寫，通過五條件即可：塑膠對環境的影響／哪一種飲料最健康／全世界最厲害的機器人／植物有感情嗎？健康→可測糖度；機器人→固定馬達下 2 m 時間；感情→改光照／水分，不要偽科學。

### 活動六：病例能不能下結論（討論，約 12 分）

四則：n＝1；同時改層數與品牌；只改層數各 5 次；洗手乳後「幾乎沒菌」。先獨立勾能／不能，再全班揭曉。

### 活動七：紙巾吸水（實作，約 26 分）

只改層數 1／2／3。當場寫操作性定義、六類控制各一項、一個混淆。時間不夠：兩組學生做 1 層與 3 層，其餘寫手續。追問：我們其實沒控制好的是什麼？

### 活動八：假設對決（練習，約 8 分）

用課堂例題寫一則強假設。同桌檢查：有 IV、DV、方向、機制、怎樣的數據會推翻它。

### 活動九：60 秒互評＋日誌契約（實作，約 12 分）

四句：問題／方法／為什麼現在還不能下結論／一個限制。加半句：本社團下一步是先模擬還是先做實驗？（先模擬。）抽不是主講的人。接著寫日誌第一頁契約；活頁本當場換掉。

## 1-6　回家作業

1. 帶成冊日誌來第 2 週。  
2. **必讀**：第 2 章「四個易混詞」「好問題五條件」「把大問題切成小問題」；第 3 章「操作性定義」「重複、隨機、樣本」。

4. 選修：把甄選稿改成「若只改一件事，則……因為……」；**不交也不扣本週分**。第 3 週末才正式交 3 候選。

## 1-7　常見迷思
