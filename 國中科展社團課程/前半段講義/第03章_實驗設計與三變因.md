# 第 3 章　實驗設計與三變因：讓證據站得住

> 本章供課後複習或卡關時查。上課請用第 1 週講義。

**補充講義**  
**一句話目標**：學會「一次只改一件事」，並把實驗寫成別人可以照做的設計。

---

## 3-1　本週學習目標

上完本週，學生能夠：

1. 正確指出操作變因、應變變因、控制變因。
2. 說明對照組／控制組存在的理由。
3. 為應變變因寫出操作性定義（怎麼量、單位、何時量）。
4. 診斷一份「看起來很忙但其實不能下結論」的實驗設計。
5. 畫出自己候選題的變因圖。

**對齊評審**：科學方法之適切性——控因及變因清楚、適當及完整；設計周全之研究計畫。

## 3-3　核心講義

### （一）實驗在回答的是因果，不是「有發生過」

科學研究常想知道：**是不是因為 A，所以 B 改變？**

要讓這句話站得住，必須盡量做到：

- 我主動改變 A（操作變因）
- 我測量 B（應變變因）
- 其他可能影響 B 的事情都盡量相同（控制變因）
- 我有一個「沒有施加 A」或「標準狀態」來比較（對照）
- 我重複多次，避免碰巧

全國評審標準寫得很直白：**控因及變因清楚、適當及完整。** 這是國中作品最容易失分的地方。

### （二）三變因（國中理化用詞，科展通用）

不同課本用詞略有出入，社團統一用這組，並括號國際常用詞：

| 本課程用詞 | 也稱 | 意義 | 設計口訣 |
| --- | --- | --- | --- |
| 操作變因 | 自變項、操縱變因 independent variable | 你**故意改**的那一件 | 一次主要只改**一個** |
| 應變變因 | 依變項、應變項 dependent variable | 你**用來判斷結果**的測量 | 必須可量化或可明確分類 |
| 控制變因 | 無關變因、控制變項 controlled variables | 你**故意保持不變**的其他因素 | 愈容易被忽略的愈要寫出來 |

**減肥比喻（幫助記憶，不當正式題）**：  
若只想知道「飲水量會不會影響體重」，則飲水量是操作變因，體重是應變變因；運動、飲食、睡眠必須控制。若運動也一起改，你就不知道是水還是運動造成的。

**正式課堂例子：紙巾吸水**

- 問題：紙巾層數如何影響吸水量？
- 操作變因：層數（1、2、3 層）
- 應變變因：30 秒內吸收的水量（mL）或增加的質量（g）
- 控制變因：紙巾品牌與尺寸、水溫、浸泡時間、水深、是否擠壓、室溫……

### （三）對照組為什麼不可少

對照組（控制組）是「用來比較的基準」。沒有它，你只知道「有數字」，不知道「跟沒處理比起來差在哪」。

例子：測試自製洗手乳殺菌。

- 若只測「用了我的洗手乳之後培養皿菌落很少」→ 可能是培養失敗，不是洗手乳厲害。
- 需要：空白（只塗無菌水）、市售對照、你的配方。  
  （注意：微生物實驗有安全限制，第 4 章會講；此處只練邏輯。）

不是每個題都叫「控制組」這三個字，但**一定要有比較的基準**。數學建模題的基準可能是已知公式；野外調查的基準可能是不同地點或不同時間。

### （四）操作性定義：把模糊詞變成測量手續

評審最怕：「我們發現比較快／比較乾淨／比較健康。」

操作性定義要回答四件事：

1. **量什麼**：時間、質量、高度、溫度、次數、面積……
2. **用什麼量**：碼錶、電子秤、直尺、溫度計、格子紙、APP……
3. **怎麼量**：從何時開始按碼錶、從哪裡量到哪裡、讀到小數第幾位
4. **量幾次**：每個條件重複 n 次，取平均，並記下最大最小

弱：測量紙直升機「飛得好不好」。  
強：自離手起至觸地，以手機慢動作對時碼錶，記錄滯空時間，單位秒，精確到 0.01 s；每種翼長重複 8 次。

### （五）一次只改一個？那進階研究怎麼辦？

國中起步：**主實驗一次一個操作變因。**

若你真的想看兩個因素（例如溫度×濃度），那是「雙因子設計」，必須有完整組合（每個溫度配每個濃度），數據量會爆增。全國作品可以做，但社團前期禁止學生一開始就雙因子，除非教師確認人力夠。分析時進階組用附錄 E 的雙因子／多因子變異數分析，不要做完兩次 t 檢定就當雙因子。

正確進階路徑：

1. 先找出最有影響的單因子
2. 再決定要不要做第二因子
3. 永遠先寫控制變因清單，再動手

### （六）重複、隨機、樣本：讓「可再現」發生

評審要「結果具有再現性」。最低限度建議（國中社團）：

- 每個條件至少 **5 次**有效重複（能 8–10 次更好）
- 生物材料（種子、叶片）每個條件至少 **10 個**個體，再取平均
- 測量順序盡量打亂，避免「先做的都是條件 A、人已經很熟練」造成系統偏差
- 事先寫：什麼情況算失敗要重做（例如紙直升機撞牆）

### （七）實驗設計一頁紙（本週產出格式）

請學生用這張表，不要寫長文：

```
研究問題：
假設：
操作變因（改什麼、幾個水平）：
應變變因（怎麼量、單位）：
控制變因清單（至少 6 項）：
對照／基準：
重複次數：
材料：
步驟（短、可複製）：
我怎麼知道設計失敗了：
```

## 3-4　課堂活動

### 活動一：5 分鐘吸水示範，15 分鐘標變因（30 分鐘）

**材料（一組）**：同品牌紙巾、杯子、水、碼錶、（若有）電子秤。

簡易版（無電子秤）：把紙巾垂入水深 1 cm 的杯子，計時 20 秒，量水線爬升高度。

任務：

1. 全班先做「1 層 vs 3 層」各 3 次（時間不夠就教師演示＋兩組學生做）
2. 立刻填三變因
3. 追問：我們**其實沒控制好**的是什麼？（放手方式、紙巾是否彎曲、讀取水線的主觀）

讓學生體驗：**設計寫在紙上很完美，手上永遠有漏網之魚。** 漏網之魚要寫進控制變因，下一次鎖住。

### 活動二：病例討論（30 分鐘）

每則先獨立判斷「能不能下結論」，再全班揭曉。

**病例 A**  
小華想知道音樂能不能讓植物長比較快。他白天給甲盆放古典樂，乙盆放在窗邊不放音樂。兩週後甲盆比較高。  
→ 不能。光照這個控制變因爆掉；也沒有「無聲但同位置」的對照。

**病例 B**  
小美測三種洗衣精去汙。她把油污量、水溫、浸泡時間、布料都固定，只改洗衣精種類，每種 6 塊布，用灰階卡片目測，請不知情的同學評分。  
→ 骨架好。目測仍主觀，可討論改秤重或拍照取平均灰階。有盲測是加分。

**病例 C**  
小明同時改紙飛機的機翼長度、配重、紙張厚度，飛了 30 次，挑最遠的那次當結果。  
→ 不能。多變因混在一起；且只取最佳值會美化結果，應報平均與離散。

**病例 D**  
小組研究坡度對小球滾下時間。同一軌道，坡度 10°、20°、30°，每種 8 次，同一人釋放，用手機腳架固定拍攝再逐格計時。  
→ 好設計。可再問：釋放方式是否真的一致？軌道是否打滑？

### 活動三：變因地圖（20 分鐘）

學生取出第 2 週三個候選題中最喜歡的一個，畫：

```
        [控制變因們]
              |
[操作變因] → [應變變因]
              |
        [對照／基準]
```

教師巡堂紅筆只打三種註記：

- 「操作變因超過一個」
- 「應變項不可測」
- 「控制清單少於 4 項」

## 3-7　常見迷思

| 迷思 | 澄清 |
| --- | --- |
| 控制變因就是對照組 | 控制變因是「保持不變的條件」；對照組是「用來比較的那一組樣本」。 |
| 改愈多變因愈科學 | 改愈多愈說不清楚是誰造成的。 |
| 應變變因可以有好幾個 | 可以有次要測量，但主問題應有一個核心指標，避免目的散掉。 |
| 做一次成功就夠 | 全國要再現性。一次成功可能是運氣。 |
