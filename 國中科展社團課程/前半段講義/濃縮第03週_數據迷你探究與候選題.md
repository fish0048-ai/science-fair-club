# 第 3 週　數據、迷你探究與候選題（濃縮）

**對應週次**：現行第 3 週（2 小時）  
**濃縮來源**：原第 7–8 章詳解  
**一句話目標**：當場走完「問題→數據→圖→結論」，並交出 3 個能進第 4 週定案的候選題。

> 圖表細節與統計加深見第 7 章、附錄 E。紙直升機模板見附錄 D。選題漏斗見附錄 A。

---

## 3-1　本週學習目標

上完本週，學生能夠：

1. 分辨原始數據、整理表、圖、結論四層，不跳級。  
2. 算出平均與全距，畫一張有軸標、單位、圖名的圖。  
3. 用單一操作變因完成迷你探究（建議紙直升機），交出日誌頁與三句結論。  
4. 每組提出 3 個通過安全與可行性的正式候選題。

**對齊評審**：四面向縮小版——有問題、有變因、有數據、有限制。

## 3-2　120 分鐘教學流程

| 時間 | 活動 | 教師做什麼 |
| --- | --- | --- |
| 0–10 | 規則：65 分強制停手算數據；編數據＝零分 | 計時器大聲 |
| 10–20 | 四層資料＋選圖＋平均／全距（用待會的數據） | 不要開 Excel 長講 |
| 20–75 | 迷你探究：只改翼長或迴紋針數；其他控制 | 模板見附錄 D；盯單一變因 |
| 75–100 | 算平均全距、畫長條圖、寫三句結論＋限制 | 巡軸標；打斷「一定比較好」 |
| 100–120 | 主題工作坊：附錄 A 漏斗，產出 3 候選；組隊 2–3 人 | 預告第 4 週定案，不鎖後期步驟 |

時間不夠：圖可手繪；Excel 當作業。進階組不要本週跑 ANOVA。

## 3-3　核心講義

### （一）四層，不許跳級

| 層 | 放哪 |
| --- | --- |
| 原始數據（含作廢） | 日誌 |
| 整理表（n、平均、全距、單位） | 說明書結果 |
| 圖 | 說明書與海報 |
| 結論 | 討論／結論，且不超過數據 |

種類比較→長條圖；隨時間／溫度連續變→折線或散佈。橫軸操作變因、縱軸應變變因，都要單位。圖名寫 n。

平均說位置，全距說散不散。兩組全距重疊很多，不要宣稱「有差」。進階檢定見附錄 E，**本週不准用 p 值裝飾**。

### （二）迷你探究規則（紙直升機）

- 一次只改一個操作變因。  
- 每個條件至少 5 次有效（能 8 次更好）。  
- 65 分停手；沒測完寫限制，**不准編**。  
- 假設示例：紙材與釋放高度相同時，翼長從 6 cm 增為 8 cm，平均滯空時間會增加。

### （三）全國級選題漏斗（第 4 週會再砍一次）

```
好奇 → 可檢驗問題 → 安全倫理 → 剩餘週次做完
    → 文獻真有缺口 → 有定量
```

任一關過不了：縮小或換備案。第 4 週定案後不任意換人（國中最多 3 人）。

後期不再全班做同一實驗。教師改當研究教練：抽日誌、要 n 與圖、用四面向問一題。

1. 當天補完日誌原始數據（當日補完不算造假；未做的不准編）。
