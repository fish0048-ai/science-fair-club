# 第 2 章　科學探究與好問題：從好奇變成可檢驗的研究

> 現行上課節奏是 **第 1–3 週濃縮課**（本章併入濃縮第 1 週）。本章是分章詳解，給課後補讀、補課或卡關時查。

**對應**：分章詳解（原第 2 週節奏）  
**一句話目標**：把「我很好奇」鍛成「一個測得到、答得完、全國評審聽得懂的問題」。

---

## 2-1　本週學習目標

上完本週，學生能夠：

1. 畫出科學探究循環，並指出科展說明書哪一章對應哪一步。
2. 分辨觀察、推論、問題、假設。
3. 用「好問題五條件」檢查自己的題目。
4. 把寬問題收成窄問題（聚焦）。
5. 寫出可檢驗的假設（含預測方向）。

**對齊評審**：研究主題（清楚、聚焦、可檢驗）；科學方法（有周全計畫的起點）。

## 2-3　核心講義

### （一）探究不是直線，但寫報告要有順序

科學家實際工作常來回修改，可是科展必須把思路整理成別人跟得上的故事。建議學生同時記住「循環」與「說明書對照」：

```
觀察現象  →  提出問題  →  查文獻、形成假設
     ↑                              ↓
  新問題 ← 結論與限制  ←  分析解釋  ←  設計並收集數據
```

| 探究步驟 | 說明書通常寫在 |
| --- | --- |
| 我為什麼在意 | 壹、前言／研究動機 |
| 我要回答什麼 | 研究目的 |
| 別人做過什麼、我的缺口 | 文獻回顧 |
| 我猜會怎樣 | 假設（可放在目的或方法前） |
| 我怎麼測 | 貳器材、參方法 |
| 我看到什麼（事實） | 肆、結果 |
| 這代表什麼（解釋） | 伍、討論 |
| 我現在能說什麼、不能說什麼 | 陸、結論 |

**關鍵紀律**：結果章只寫「數據顯示什麼」；解釋放到討論。國中作品常把兩章混在一起，評審會覺得邏輯鬆。

### （二）四個易混詞（必須當堂練到會）

| 詞 | 意思 | 例子 |
| --- | --- | --- |
| 觀察 | 五官或儀器直接得到的事實 | 這杯糖水 3 分鐘後杯底仍有固體 |
| 推論 | 用已知知識解釋觀察，可能錯 | 可能已經飽和了 |
| 問題 | 你要追究的疑問，最好能測 | 水溫如何影響蔗糖溶解度？ |
| 假設 | 對問題的暫時回答，必須可被數據打槍 | 在 1 atm 下，水溫愈高，100 mL 水能溶解的蔗糖質量愈大 |

口訣：**觀察是看到的，推論是想到的，問題是要查的，假設是敢被打臉的。**

假設寫作公式（國中夠用）：

> 若 **（操作變因）** 改變，則 **（應變變因）** 會 **（上升／下降／不變）**，因為 **（簡短原理）**。

弱假設：「溫度跟溶解有關。」→ 無法判斷怎樣叫對、怎樣叫錯。  
強假設：「當水量與攪拌固定時，水溫從 20°C 升到 60°C，蔗糖溶解度會明顯增加。」

### （三）好問題五條件（全國主題「清楚且聚焦」的操作版）

用這五個勾勾檢查。少一個，後期通常會爆。

1. **可檢驗**：能用實驗、調查、測量或數學得到證據。  
   ×「外星人存不存在？」　○「本校頂樓與一樓的紫外線強度差多少？」
2. **可測量**：應變項有單位、有工具、有紀錄方式。  
   ×「哪種肥料讓植物比較開心？」　○「哪種氮肥濃度使綠豆 7 日苗高平均較大？」
3. **單一聚焦**：一段時間內主要只追一個核心問題。  
   ×「研究塑膠對環境、人體、海洋、經濟的影響並做出產品」  
   ○「比較兩種洗劑濃度對油汙布的去汙時間」
4. **安全可行**：時間、器材、倫理、經費在國中社團做得到。  
   × 自製煙火、培養未知病原、傷害脊椎動物  
   ○ 用紙材、食材級藥品、校園植物、物理裝置
5. **有新意空間**：不是課本原實驗複製；至少有一個「比前人多問的點」。  
   ×「驗證光合作用需要光」（國小就做過）  
   ○「遮光程度與葉片澱粉顯色面積的定量關係」或「在前人濾材研究上改測流速與濁度」

### （四）把大問題切成小問題（聚焦技術）

學生最常犯的錯：問題像百科全書。教他們用「加條件、加對象、加指標」。

**原問題**：空污對身體不好，我們想改善空污。

收斂過程：

1. 對象縮小：本校前門 vs 後門  
2. 指標具體：PM 無法人人測，可改「交通尖峰時段懸浮微粒代理指標」或改做「教室開窗策略與 CO₂／舒適度」（視器材）  
3. 若器材不足，換可測的相關問題：例如「不同口罩材質對麵粉模擬粉塵的阻隔質量差」

**收斂句型**：

> 在 **（條件／地點／材料）** 下，**（操作變因）** 如何影響 **（可測量的應變變因）**？

### （五）三種全國能打的問題類型（給學生地圖，避免只會一種）

1. **機制型（為什麼）**  
   例：為什麼加鹽會改變冰的熔化？核心是物理／化學原理。
2. **比較型（哪一個、差多少）**  
   例：三種市售洗碗精在固定油量下的去油效率。注意：不要做成廣告，要做成控制良好的比較。
3. **設計型（如何更好）**  
   例：如何設計擋風板使腳踏車雨衣更穩。必須有量化指標（翻覆次數、阻力、乾燥時間），否則會變成美工發明展。

數學科另有：模式發現、證明、模擬、資料規律。仍需「清楚問題＋可檢查的論證」。

### （六）從好奇清單到候選題（本週只要「候選」，不要定案）

定案放在第 8–9 週，因為那時才會文獻檢索與可行性檢核。本週任務是**產生高品質原料**。

鼓勵來源（實施要點也強調生活性、鄉土）：

- 校園：積水、悶熱、噪音、午餐廚餘、運動場積沙
- 家庭：清洗、保存、節能、食材
- 在地：河川、農業、地質、產業廢棄物（只做安全範圍）
- 課堂：課本實驗的「然後呢」——改變一個沒被討論的變因

## 2-4　課堂活動

### 活動一：從觀察到問題（25 分鐘）

準備 4 個真實刺激（擇一組即可）：

- 一張「洗手臺水垢」照片
- 一張「操場雨後積水」照片
- 一瓶搖過的油醋醬
- 一段「口罩起霧眼鏡」的經驗

每組完成表格：

| 我觀察到 | 我推論（可能錯） | 我可以問的可測問題 |
| --- | --- | --- |

教師巡堂時只抓一件事：問題裡有沒有**可測的東西**。

### 活動二：好問題診所（30 分鐘）

請學生把下列「壞問題」改寫成通過五條件的版本。先個人 8 分鐘，再小組 10 分鐘，最後全班收 3 題示範。

1. 塑膠對環境的影響是什麼？
2. 哪一種飲料最健康？
3. 怎麼做出全世界最厲害的機器人？
4. 植物有感情嗎？
5. 我們學校的自然課好不好玩？

**教師提示（改寫方向，不是標準答案）**：

1. → 在固定日照與雨量模擬下，不同粒徑塑膠碎片對綠豆 10 日發芽率的影響？（仍要注意塑膠微粒清理與倫理，可改用安全替代材料討論「粒徑／覆蓋率」）
2. → 固定體積下，三種市售含糖飲料的糖度（或密度）比較——「健康」太大，改成可測指標。
3. → 在固定馬達與電池下，輪徑如何影響自走車 2 公尺直線時間？
4. → 植物無法回答感情；可改「不同撫觸頻率是否影響豆苗高度」——但仍要小心偽科學，必須有對照（有人靠近但不觸摸）。更建議改成光照／水分等有理論基礎的題。
5. → 不是自然科學可檢驗問題；可改「不同座位區的噪音分貝與學生自評專注」屬行為調查，國中組較少、倫理需同意書，不建議當第一題。

### 活動三：假設對決（25 分鐘）

每人選活動一的問題，寫一則強假設。同桌用紅筆檢查：

- [ ] 有操作變因
- [ ] 有應變變因
- [ ] 有預測方向（增／減／不變）
- [ ] 寫得出「如果數據相反，假設就失敗」

請 2 位學生上台，全班練習「一句話打槍」：說出怎樣的數據會推翻它。

## 2-7　常見迷思

| 迷思 | 澄清 |
| --- | --- |
| 假設最後一定要被證明對 | 錯。被數據推翻的假設仍是好科學。全國評審吃這套。 |
| 問題愈偉大愈容易得獎 | 錯。偉大但測不到＝主題失敗。 |
| 要先有完美題目才能開始 | 錯。好問題是改出來的。本週先量產，第 6、8 週用文獻與可行性砍題。 |
| 假設就是目的 | 目的是「要找出什麼關係」；假設是「我預測關係長怎樣」。 |
