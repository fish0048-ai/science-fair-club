# 第 11 週　說明書、海報與口試

**上課時數**：2 小時  
**一句話目標**：把研究變成可被評審檢驗的表達——說明書骨架、海報邏輯、3 分鐘口頭稿；封面匿名以當年科教館公告為準。

> **不代做海報。** 全組都要能講，不是一人背稿。

---

## 11-1　本週學習目標

1. 說明書目錄對得上實際做過的事；300 字摘要能含問題、方法、一個數字、一個限制。  
2. 海報五塊：問題／方法／圖／結論／限制，3 公尺外看得懂軸。  
3. 3 分鐘口頭＋預備被問日誌某一頁。  
4. 知道現場要帶：成冊日誌、文獻、原始數據。

**對齊評審**：展示及表達能力。

---

## 11-3　核心講義

### （一）摘要四件（約 300 字）

1. 問題（改什麼、量什麼）  
2. 方法（n、對照、一個關鍵控制）  
3. 一個帶單位的結果  
4. 一句限制或下一步  

不要：動機故事寫一半、沒有數字。

### （二）海報五塊

| 塊 | 評審 3 秒要看到 |
| --- | --- |
| 問題 | 一句話 |
| 方法 | IV／DV／n |
| 圖 | 軸標、誤差線、圖名 |
| 結論 | 不超過數據 |
| 限制 | 至少一句誠實的 |

美工顏色輸給「黑白列印還看得懂」。

### （三）口試

評審問日誌與限制，不問你背得順不順。  
練習：把日誌打開到原始數據那頁，用手指著講。  
全組輪流當主講；抽到誰誰就要答。

現場常見要帶（以當年公告為準）：說明書、海報、研究日誌、文獻資料、可替代實物的照片或影片。

## 11-6　回家作業

1. 說明書草稿缺的章補上。  
2. 每人能講別人負責的那一塊。  
3. 第 12–16 週彈性：帶「還缺哪批數據／哪張圖」。
