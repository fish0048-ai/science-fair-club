# 第 9 週　比較、修正模型、第二輪預測

**上課時數**：2 小時  
**一句話目標**：完成 ⑦ 比較「第一輪預測 vs 實際」；⑧ 修正模型（舊表留下）；⑨ 寫出**第二輪預測**。正式的第二輪驗證（⑩）下週做。

> **不鎖新實驗食譜。** 修正模型不是作弊；把第 ⑤ 步改掉假裝沒改才是。

---

## 9-1　本週學習目標

1. 用 n、離散、誤差線，對第一輪預測判相符／部分相符／不相符。  
2. 寫出 v2：改了哪一條假設或哪個係數。  
3. 凍結第二輪預測表（新條件或同一條件的新預測值）。  
4. 若方法不可行：轉備案，仍須新的 ①②。

**對齊評審**：數據是否足以支撐「模型被支持或被修正」。

## 9-3　核心講義

### （一）三種比較（要有 n 與誤差線）

| 說法 | 何時可用 |
| --- | --- |
| 相符 | 排序或趨勢與第一輪預測一致，誤差線讀得下去 |
| 部分相符 | 大方向像，但一檔重疊或一條假設被打槍 |
| 不相符 | 排序相反，或預測值完全在誤差線外 |

不相符是合格研究。

### （二）⑧ 修正 vs 作弊

| 合格 | 不合格 |
| --- | --- |
| 留下 v1 預測表，另寫 v2 與原因 | 把 v1 擦掉改成和數據一樣 |
| 寫「先導估的係數要改成＿＿」 | 用第 8 週全部數據調到完美就當結論、不再做 ⑩ |
| 縮小問題或轉備案 | 改原始數據 |

### （三）第二輪預測要檢驗什麼

最好檢驗 v2 的**新推論**（例如：若重量才是主因，則同翼長加配重會怎樣）。  
若只能補 n，也要寫「v2 預測這檔平均會落在＿＿」。

### （四）比較句診所

弱：「所以我們的模型比較好。」  
要：第一輪預測＿＿；正式數據＿＿（含重疊）；因此＿＿。v2 改＿＿。

### （五）填空

原本假設＿＿；數據顯示＿＿；v2 改為＿＿；第二輪預測＿＿。
