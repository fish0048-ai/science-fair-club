# 第 4 週　主題定案與分組

**上課時數**：2 小時  
**一句話目標**：用全國級選題漏斗，把第 3 週的 3 個候選砍成 **1 個定案題**（可留 1 個備案）；組隊 2–3 人，人人能講問題與為何可行。

> 本週開始依各組題目教練，**不鎖死實驗步驟**。漏斗與檢核表見附錄 A，本屆題型見附錄 F。

---

## 4-1　本週學習目標

上完本週，學生能夠：

1. 用漏斗六關檢查候選題：可檢驗、安全、期末前做完、文獻缺口、定量、單一應變項。  
2. 完成主題定案書：問題、假設雛形、科別（看核心方法）、安全燈、為何可行、備案一句。  
3. 確認作者 2–3 人，寫組約：不換人掛名、數據共有、全組會講。  
4. 列出下週計畫書要補的空格（變因、n、材料），仍不寫食譜式步驟。

**對齊評審**：研究主題（清楚、聚焦、可檢驗、可行）。全國輸在做不完與變因不清，不在題目聽起來不夠偉大。

## 4-2　120 分鐘教學流程

| 時間 | 活動 | 教師做什麼 |
| --- | --- | --- |
| 0–12 | 重申：小題做完＞大題做半套；抽第 3 週合格圖 | 沒圖者本週只准縮小版備案 |
| 12–28 | 短講：漏斗六關、科別與方法、紅燈不得定案；砍題示範 | 不替學生決定步驟 |
| 28–75 | 教師巡迴漏斗面談：每組約 8–10 分 | 只問安全、變因、兩個月、缺口 |
| 75–108 | 寫主題定案書＋組約 | 3 人上限；相近題可併組，仍只准一個 DV |
| 108–120 | 每組 60 秒宣布定案；登記科別與安全燈 | 作業：材料清單估價，不急著買齊 |

## 4-3　核心講義

### （一）漏斗六關，任一關倒了就縮小

```
好奇故事  →  可檢驗問題  →  安全倫理  →  期末前做完
    →  文獻真有缺口  →  有定量與操作性定義
```

| 關 | 過關長相 | 倒了怎麼辦 |
| --- | --- | --- |
| 20 秒問題 | 改什麼、量什麼，外人聽得懂 | 加條件、加對象、加指標 |
| 安全 | 非紅燈；黃燈有監督與展場替代 | 換代理、換材料、換備案 |
| 時間 | 第 6 週能預試、期末前 n≥8 | 砍水平、砍第二應變項 |
| 缺口 | 方法／指標／條件／解釋寫死一句 | 再查一件最像的前人 |
| 定量 | DV 有單位、手續、作廢規則 | 把「比較好」改成可測 |
| 單一 | 一段時間只追一個核心 DV | 其餘當下學期或限制 |

### （二）定案書要有的格子（不是作文）

```
一句話問題：
假設雛形（若 IV 則 DV 因為機制）：
可能科別（核心方法）：
IV 與水平（≤3 檔）：
DV 操作性定義：
控制先列 6 項（下週再補）：
n 計畫（每條件 ≥8）：
安全燈：紅／黃／綠　　展場改擺：
最像的前人＋缺口類型：
為何兩個月做完：
備案（一句）：
作者 2–3 人與分工一句：
```

**科別提醒**：選科看你實際要做的方法，不要猜哪科比較好獎。濾材走吸附定量→化學或應科（三）；走結構與流量→應科（一）。

### （三）面談時教師會問的四句（先自己答）

1. 一次改幾件事？第二件為什麼現在不做？  
2. 別人照你的定義量，趨勢會像嗎？  
3. 植物／季節／訂器材，從本週算得到結果日嗎？  
4. 失敗了，備案是哪一題？

合成示範（不當各組處方）：「淨化全校飲水＋抗菌＋量產」→ 砍成「固定水頭下兩種安全濾材的流速與濁度代理；不下醫療結論」。

## 4-6　回家作業

1. 定案書給家長看一遍：能不能 20 秒講完。  
2. 列出材料與估價（教師審安全後才買）。  
3. 必讀：附錄 A；本屆題型附錄 F（對自己的題對燈號）。

## 4-7　常見迷思

| 迷思 | 澄清 |
| --- | --- |
| 題目愈大愈全國 | 做不完的大題地方賽就倒。 |
| 教師會告訴我們步驟 | 教練問品質；步驟由計畫書長出來。 |
| 定案後還能任意換人 | 國中最多 3 名作者，定案後不掛名。 |
| 沒過第 3 週圖也能定大題 | 本週只准縮小版備案。 |
