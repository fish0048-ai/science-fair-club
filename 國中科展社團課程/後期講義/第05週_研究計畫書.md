# 第 5 週　研究計畫書

**上課時數**：2 小時  
**一句話目標**：寫出對齊說明書骨架的計畫書 v1——先有方法架構，再採買；步驟只寫到「做什麼、幾次」，不抄實驗書當研究。

> **不鎖各組實驗步驟。** 教師審的是變因是否單一、兩個月是否做完、安不安全。

---

## 5-1　本週學習目標

上完本週，學生能夠：

1. 交出計畫書 v1：問題、假設、三變因、對照、操作性定義、重複、材料、安全、文獻 3 筆、預估時程。  
2. 步驟只寫架構層級（例：「三種濃度各測 10 次」），能說明每一步在回答哪句問題。  
3. 全組互問 3 題後修改；知道預實驗後方法會改（v1.1）。

**對齊評審**：科學方法（設計周全之研究計畫）。

## 5-2　120 分鐘教學流程

| 時間 | 活動 | 教師做什麼 |
| --- | --- | --- |
| 0–10 | 出示說明書目錄：計畫書＝未來說明書骨架 | 不是美工週 |
| 10–32 | 短講：計畫檢核 8 項；反例「看起來很忙但不能做」 | 不展示某組真實失敗 |
| 32–95 | 分組撰寫 v1；教師輪流審變因與時程 | 不代寫步驟 |
| 95–120 | 交換計畫互問 3 題；作業採買清單 | 教師審安全後才買 |

## 5-3　核心講義

### （一）計畫書對照說明書

| 計畫書現在寫 | 以後說明書 |
| --- | --- |
| 動機、目的、假設 | 壹、前言 |
| 最像的 3 筆文獻＋缺口 | 文獻回顧 |
| 材料、安全、步驟架構、預估數據表 | 貳參 器材方法 |
| （本週空白） | 肆 結果 |
| 預期限制與備案 | 伍陸 討論結論 |

沒有計畫就採買＝先買一堆用不到的東西。沒有對照與 n，步驟寫得再細也不是研究。

### （二）8 項檢核（缺一項退回）

1. 問題 20 秒能講完，只有一個核心 DV  
2. 假設含機制，能被數據打槍  
3. IV 水平 ≤3；控制 ≥6  
4. 操作性定義四問寫死  
5. 每條件 n 計畫 ≥8（生物材料個體數另加）  
6. 有比較基準（對照或標準條件）  
7. 安全燈與防護；展場替代  
8. 時程：第 6 週預試、第 7–8 週收數據、後面留分析與表達  

**反例（合成）**：「本週做完文獻、買齊材料、測 12 種品牌、順便做問卷與產品包裝。」→ 忙，但不可檢驗、做不完、DV 太多。

### （三）步驟只寫架構

可以寫：配製三種濃度 → 各隨機測 10 次 → 當日把原始值寫進日誌。  
不要寫：把某本實驗書的 18 步當自己的發明。  
評審問「這一步在回答哪句問題？」答不出來就刪。

預估數據表先畫空表：列條件、欄重複、底列平均／全距／s。空表逼你面對 n 夠不夠。

## 5-4　課堂活動

1. 用 8 項檢核表互評。  
2. 寫 v1；空表畫在日誌。  
3. 互問：「一次改幾件？」「兩個月做完嗎？」「這步在回答哪句？」

## 5-6　回家作業

1. 補滿文獻 3 筆（含屆別／科別／缺口類型）。  
2. 材料清單給教師審安全。  
3. 全組每人能講計畫 60 秒。

## 5-7　常見迷思

| 迷思 | 澄清 |
| --- | --- |
| 步驟愈細愈科學 | 架構對得上問題才科學。 |
| 計畫不能改 | 預試後應改成 v1.1；改方法要記日誌。 |
| 一人寫、兩人掛名 | 口試會拆穿。 |
