# 第 13 週　核心圖表定稿

**上課時數**：2 小時  
**一句話目標**：一張圖回答問題。軸標、單位、n、誤差線（或全距）、圖名、黑白列印仍可讀。

> 彈性週。**不鎖實驗步驟。** 進階組附錄 E 的圖要事先寫在計畫裡，不當場新發明檢定。

---

## 13-1　本週學習目標

1. 選對圖種（比較用長條、連續用折線或散佈）。  
2. 定稿一張核心圖＋一張整理表。  
3. 圖名寫得出 n；誤差線與重疊判斷寫在圖下或結果段。

**對齊評審**：展示及表達；科學方法（適當用數學）。

---

## 13-2　120 分鐘教學流程

| 時間 | 活動 | 教師做什麼 |
| --- | --- | --- |
| 0–15 | 投影不合格圖：沒軸、3D、沒 n |  |
| 15–30 | 短講：選圖、誤差線、圖下文字 |  |
| 30–100 | 定稿；列印或投影自查黑白 | 巡軸標 |
| 100–120 | 他組 30 秒讀你的圖，講得出問題嗎 |  |

## 13-3　核心講義

### （一）核心圖檢核

- [ ] 橫軸 IV＋單位　- [ ] 縱軸 DV＋單位  
- [ ] 圖名含 n　- [ ] 不是 3D　- [ ] 黑白仍可辨  
- [ ] 誤差線或全距　- [ ] 圖下有「重疊與否」一句  

### （二）一張圖一個問題

海報不要五張小圖搶同一個 DV。附圖可放附錄或說明書。評審先被核心圖說服。
