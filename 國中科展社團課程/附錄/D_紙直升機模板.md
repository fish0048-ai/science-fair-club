# 第 3 週紙直升機模板（教師印製說明）

A4 直向。建議 70–80 磅影印紙。每人至少 3 張（三種翼長）。

## 標準機身（控制變因：除翼長外皆同）

```
        翼長 L（本週改這個）
<------------------------>
┌──────────┬──────────┐  ↑
│   左翼    │   右翼    │  翼寬建議固定 2 cm
└──────────┴──────────┘  ↓
           ││
           ││  軀幹寬約 1.5–2 cm
           ││  軀幹長約 8 cm（三種機相同）
           ││
        ┌──┴──┐
        │ 腳  │  底部夾 1 個迴紋針（位置相同）
        └─────┘
```

## 做法

1. 由短邊中線對折再打開，當中線。
2. 上方切（或剪）出兩片翼，**只改變 L**：6 cm、8 cm、10 cm。
3. 左翼、右翼向相反方向折，成螺旋槳。
4. 下方兩側向中線折成軀幹，腳部夾迴紋針。
5. 三種機用鉛筆在翼上寫 6 / 8 / 10，避免搞混。

## 釋放

- 高度 2.0 m（門框預先貼膠帶標記）
- 手持軀幹、翼朝上，鬆手即計時，觸地停錶
- 撞到人、桌、門則該次作廢並記日誌

課堂上若時間不夠，可只做 6 cm vs 8 cm 兩水平，但 n 仍至少 6。
