# 附錄 A　全國級選題漏斗與可行性檢核

> 使用時機：第 3 週末（迷你探究過關後）與第 4 週定案。教師與學生面對面勾選，不要讓學生自己全打勾交差。本屆題型示例見附錄 F。模擬路徑見附錄 G。第 1–2 週先對齊技能，不拿各自的稿過漏斗。

---

## A-1　選題漏斗（口頭版）

```
好奇故事  →  可檢驗問題  →  安全倫理  →  期末前做完
    →  文獻真有缺口  →  有定量與機制／應用深度  →  能先模擬再驗證
```

任一關過不了：改題、縮小、或換備案。不要用「我們很努力」跳關。

## A-3　常見「看起來很全國、其實會爆」的題

| 題型 | 為什麼危險 | 可能的縮小 |
| --- | --- | --- |
| 自製疫苗／抗癌／殺菌萬能配方 | 倫理、微生物、誇大 | 改安全材料的定量比較，不下醫療結論 |
| 空污與疾病因果 | 測不到、變因爆炸 | 改可測代理變因或室內簡單模擬 |
| 時間旅行／熵定律／綠氫閉環／滅菌產品 | 不是國中能自己產生的證據，或紅燈 | 改單擺、擴散、薄膜單因子、安全材料性質 |
| 機器人／APP 大系統 | 做成資訊展而非研究 | 鎖一個可測性能指標 |
| 同時十種濾材十種水質 | 做不完、不聚焦 | 一種水質、三種濾材、兩個指標 |
| 校園生態「全面調查」 | 變成標本展示 | 一個分類群＋一個環境因子 |

## A-4　第 4 週定案會議流程（後期要用，先放在此）

1. 每組 4 分鐘：講最想做的題 + 最像的前人作品 + 缺口
2. 同學用評審四面向各問一題
3. 教師用本檢核表裁決
4. 當場寫「主題定案書」：問題、科別、組員、分工、模擬構想、器材清單、時程（模擬凍結／驗證實驗／分析）
5. 沒過關的組當天改做備案，不拖過第 5 週
