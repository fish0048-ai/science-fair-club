# 附錄 F　本屆題型教練卡（115 甄選稿）

> 依本屆報名甄選表的**題型**編寫，不鎖各組實驗步驟。公開站不列學生姓名。  
> 上課用：第 1 週改寫問題、第 2 週過安全燈、第 4 週定案。程度落差大時，**全班同一套漏斗，各組不同縮小法**。

本屆多數學生**已經有草稿題**，也有縣市科展或動手玩科學得獎經驗。講義不再假設「從零想題」。前期任務改成：把草稿砍成**測得到、期末前做完、安全綠／黃燈**的一題。

---

## F-1　本屆程度怎麼看

| 觀察 | 對講義的意思 |
| --- | --- |
| 多人已會變因表、重複 3 次、甚至 ImageJ／色差 | 第 1 週少講「什麼是操作變因」，多練**砍題**與**只追一個應變項** |
| 詞彙常常超前方法（IPN、綠氫、時間扭曲、熵） | 評審看**你自己能量到的數字**，不看專有名詞密度 |
| 有人完全沒參賽經驗、有人已全國／縣市得獎 | 迷你探究（紙直升機）仍全班做，當**程度校正**，不當全國題 |
| 三份草稿都圍繞「綠繡眼鳥巢＋仿生」 | 可組一組，但必須先拆成**一個**核心問題，禁止同週測保溫＋通風＋排水＋成品 |

**本屆最低門檻（全班）**：可檢驗問題、單一核心應變項、n≥5、日誌手寫、安全過關。  
**進階組加碼（教師點頭）**：影像分析、感測器、相關／迴歸、附錄 E。亂報 p 值仍禁止。

## F-2　題型燈號（匿名）

| 代號 | 草稿方向 | 燈號 | 講義程度／第 4 週前必須縮小成 |
| --- | --- | --- | --- |
| A | 飲品成分 × 脂溶性辣油模擬物；定量殘留、色差／ImageJ | 綠偏黃 | 一次只改「脂肪有無」或「乳蛋白有無」；溫度先當控制。n≥5。色差要固定光源與距離 |
| B | 綠繡眼巢構造／巢材／微氣候／仿生盆器或隔熱牆 | 黃 | 三稿併一組可以。本學期只准一個應變項：例如「固定風速下，巢壁透氣時間」或「固定水量下，排水時間」。活鳥、拆繁殖中的巢＝紅燈；只用棄巢或人工仿巢 |
| C | 錦鯉群體行為 × 水質／天氣預警 | 黃 | 先在家缸把「行為指標」寫死（例如 1 分鐘內聚群次數），再談戶外大池。不傷害魚。相關≠因果 |
| D | 廢棄物製抗菌膜＋交聯網路＋鋁箔鹼水產氫閉環 | 紅／做不完 | 整包刪。備案：安全材料的「薄膜透光或吸水」單因子。致病菌抗菌＝紅燈；產氫＝黃燈且學校難監督 |
| E | 直鏈／支鏈澱粉比 × 米紙薄膜性質 | 綠偏黃 | 可做。一次只改澱粉比或甘油％其中一個。應變項選一個：乾燥時間、破裂荷重、或吸水增重。別同時追「取代塑膠」大結論 |
| F | 時間扭曲／相對論文獻整理 | 紅（不是實驗） | 改成可測代理：例如「不同重力／擺長對單擺週期」（國中能做）。純查資料≠科展研究 |
| G | 熵增定律、找「違反熵增」 | 紅（題太大） | 改成擴散：同體積、不同溫度，墨水前緣移動距離 vs 時間。不談宇宙、不談永動機 |
| H | 木構模型 × 地震模擬台；軟腳蝦（軟弱層） | 綠偏黃 | 應變項寫死：同一搖幅下「頂層水平位移」或「至倒塌的搖次」。每次只改一個結構特徵 |
| I | 車身外形 × 空氣阻力；迴力車＋斜坡滑行距離 | 綠 | 可做。摩擦與輪子要當控制。進階：同車體、改外殼；錄影測末速。滑行距離只是代理變因，討論要誠實 |
| J | 蜂膠／辛香料噴灑吐司防霉 | 黃 | 量「第幾天可見菌落」或面積比例，不要只說比較防霉。濃度與噴量要定量。不要培養未知環境菌去鑑定 |
| K | 嬰幼兒用品「滅微生物」且測材料劣化 | 紅 | 致病／環境微生物培養＝紅燈。改安全代理：例如「不同清洗液對矽膠片重量或硬度」——仍須教師審材料 |
| L | 河床粒徑與蟹類化石／現生分布 | 黃 | 戶外取樣要監督。本學期可做「兩河段 230 目篩分的粒徑組成比較」。別承諾做出完整地史年表 |
| M | 甄選表空白、尚無題 | 先補技能 | 第 1–3 週走濃縮課；第 3 週末仍要 3 候選 |

## F-3　第 1 週改寫句型（給學生抄）

把長標題改成：**若……（只改一件事），則……（有單位的量）會……。**

| 太大 | 本學期可測的縮小例（示例，不是指定步驟） |
| --- | --- |
| 飲品如何解辣＋乳化包裹效能 | 10°C 下，全脂 vs 脫脂牛乳洗去載體上固定量辣油後，紅色殘留面積％有無不同 |
| 鳥巢仿生盆器／隔熱牆 | 同體積仿巢，只改編織密度，測 50 mL 水排空時間 |
| 魚群預警智慧養殖 | 餵食前 5 分鐘，溶氧下降時，鏡頭畫面中個體間平均距離是否變小 |
| 天然抗菌保鮮膜＋綠氫 | 刪題。改：甘油％對澱粉膜乾燥後質量的影響（若選材料組） |
| 時間扭曲 | 改單擺或沙漏：擺長與 10 次擺動總時間 |
| 熵 | 燒杯水溫 20°C vs 40°C，一滴墨水 60 秒擴散直徑 |
| 抗震巨人 | 同一搖台程式，一樓有無側向支撐，頂層位移 |
| 車身空氣阻力 | 同一底盤兩種外殼，斜坡釋放後水平滑行距離（承認輪阻） |
| 蜂膠防霉 | 同配方噴量，記錄長出可見斑點的天數（n=5 片吐司） |

## F-4　教師巡堂口訣（不鎖步驟）

1. **20 秒講不完就太大。**  
2. **應變項超過一個，先砍到一個。**  
3. **專有名詞能否改成國中能量的動作？** 不能就換題。  
4. **紅燈不講價。** 滅菌、未知菌、傷害動物、爆炸、人體傷害試驗。  
5. **詞彙像大學、方法像國小**（只測 3 次、沒單位）→ 本週補 n 與操作型定義，不補更多因子。
