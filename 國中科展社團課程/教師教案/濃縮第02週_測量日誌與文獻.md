# 第 2 週教案｜測量、日誌與文獻

> 教師用。請勿印入學生講義。對應學生講義：第 2 週。課後補充見第 4–6 章。

| 項目 | 內容 |
| --- | --- |
| 領域／科目 | 自然科學領域（彈性學習／社團） |
| 實施年級 | 國民中學七～九年級 |
| 教學節數 | 共 2 節（120 分鐘），本次為連續第 1–2 節 |
| 單元名稱 | 重複測量、日誌倫理、文獻缺口 |
| 跨科概念 | 科學與生活；系統與尺度 |
| 主攻評審面向 | 科學方法（可再現）；展示（日誌與文獻）；安全倫理 |

## 一、設計依據

### （一）學習表現

- **pe-IV-2** 正確安全操作並詳實記錄。
- **an-IV-1** 知道測量與推論有限制。
- **ah-IV-1** 評估證據夠不夠。
- **po-IV-1、pc-IV-1、tc-IV-1** 有計畫檢索並對前人報告保持懷疑。
- **Ea-IV-1**（連結）基本物理量。

### （二）學習內容

- 誤差、有效性、有效數字、全距與樣本標準差；科教館安全規則的紅黃綠。
- 日誌規格與引用；歷屆作品四格拆解找缺口類型。

### （三）領綱核心素養

- **自-J-A2、自-J-B1、自-J-C1**

### （四）議題融入

- **安全教育、品德教育、資訊教育**（合法引用、不把別人數據當自己的）。

### （五）跨領域連結

- 數學：平均、全距、樣本標準差。國語文：APA 草稿（屆別、科別）。

---

## 二、學習目標

1. 同一落下事件測 8 次，報原始值、平均、全距、s、有效數字與一個系統誤差。
2. 為**課堂例題**標紅黃綠。
3. 能說日誌硬規格與寫錯改法。
4. 用四格拆教師指定的同一件優勝作品；缺口標類型。

---

## 三、學生先備知識

- 第 1 週契約與課堂變因表。未帶日誌者先補。本週測量對象全班同一物；甄選稿過燈當作業。
