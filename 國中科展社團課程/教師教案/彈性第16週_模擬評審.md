# 第 16 週教案｜模擬評審與修改清單

> 教師用。研究教練彈性週。請勿印入學生講義。**下週才是成果發表。本週找洞、列清單。不鎖實驗步驟。**

| 項目 | 內容 |
| --- | --- |
| 領域／科目 | 自然科學領域（彈性學習／社團） |
| 實施年級 | 國民中學七～九年級 |
| 教學節數 | 共 2 節（120 分鐘） |
| 單元名稱 | 5+5 分鐘演練；帶得走的修改清單 |
| 跨科概念 | 各組自訂 |
| 主攻評審面向 | 四面向總體檢 |

---

## 一、設計依據

- 學習表現：**pc-IV-2、pc-IV-1、ai-IV-3**
- 學習內容：發表規格（時間、繳交物）先跑一輪。
- 核心素養：自-J-B1、自-J-C2、自-J-A3
- 議題：時間管理、誠實限制

## 二、學習目標

1. 完成一次 5 分鐘說明＋5 分鐘問答（可用海報草稿或簡報）。
2. 用四面向互評，寫 3 項下週前必改。
3. 核對日誌、數據、文獻是否帶得到現場。

## 三、先備

說明書或海報草稿。沒有者本週用學習單三句結論上場，評量改看限制是否誠實。

## 四、活動

| 教學活動內容及實施方式 | 時間 | 學習評量 |
| --- | --- | --- |
| **引起動機**　宣布計時與互評表。 | 0–10 分 | 知規則 |
| **發展活動**　分組演練。教師當評審只問四面向。 | 10–100 分 | 5+5 跑完 |
| **綜合活動**　修改清單＋繳交物核對。 | 100–120 分 | 3 項必改 |

## 五、規準

優良：逾時能自己收、問答不讀稿。通過：有結構、有清單。待加強：超時嚴重或無人能答。

## 六、差異化

沒海報：用紙本圖。數據不足：清單第一條必須是「縮小結論」不是「加金蔥」。

## 七、準備

計時器、互評表、延長線。原則上無新實驗。

## 八、參考

原第 17 週流程；濃縮第 1 週四面向。
