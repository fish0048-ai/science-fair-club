# 教師教案區｜格式說明與 108 課綱對照

> 本區給**教師上課**使用，不印入學生講義。格式對齊十二年國民基本教育（108 課綱）自然科學領域**素養導向教學方案**，並對應全國科展評審四面向。

---

## 一、這份教案在對齊什麼

| 層次 | 依據 | 本社團怎麼用 |
| --- | --- | --- |
| 總綱核心素養 | 自主行動 A、溝通互動 B、社會參與 C | 每週只列與本堂高度相關的項目，不灌水全勾 |
| 領綱核心素養 | 自然科學領域 自-J-A1～C3 | 用國中階段（J）代碼 |
| 學習重點 | 學習表現＋學習內容須互相連結 | 表現寫「學生做得出什麼」；內容寫探究時用到的知識起點 |
| 探究歷程 | 發現問題 → 規劃與研究 → 論證與建模 → 表達與分享 | 科展是這條路走得較深、較長的版本 |
| 全國科展 | 研究主題；創意／學術／實用；科學方法；展示及表達 | 每週教案都標「本週主攻哪一面向」 |
| 課程屬性 | 彈性學習／社團，不是部定自然科進度 | 不取代教科書章節，但能力完全對齊領綱探究能力 |

每週 2 節共 **120 分鐘**。教學活動採素養導向常用三段：**引起動機 → 發展活動 → 綜合活動**，並讓「學習目標、學習活動、學習評量」三者一致。

---

## 二、教案欄位（每週同一套）

1. **基本資料**：領域／科目、年級、節數、單元名稱、對應學生講義  
2. **設計依據**：學習表現、學習內容、領綱核心素養、議題融入、跨領域連結  
3. **學習目標**：可觀察、可檢核的行為表現  
4. **學生先備知識**  
5. **教學活動設計**：時間、教師做什麼、學生做什麼、評量  
6. **學習評量規準**：優良／通過／待加強  
7. **差異化與補救**  
8. **教學準備與安全**  
9. **參考資料**  
10. **教學省思欄**（上課後手寫）

第 9–16 週採**研究教練教案**：檢核表與時段固定，**不預寫該組實驗步驟**。等學生主題定案後，再在省思欄或自訂附件補專章。

## 三、本課程常用學習表現（第四學習階段）

代碼依《十二年國民基本教育課程綱要　自然科學領域》。課堂上請用完整代碼，向學生則說人話。

| 代碼 | 本社團常用的學生版意思 |
| --- | --- |
| po-IV-1 | 有計畫地觀察生活與資料，察覺問題 |
| po-IV-2 | 能分辨「適不適合用科學方法來探究」 |
| pe-IV-1 | 分清自變項／應變項，規劃有可信度的探究（含重複測量） |
| pe-IV-2 | 正確安全操作器材，客觀觀察或量測並詳實記錄 |
| pa-IV-1 | 用表、圖、數學整理數據 |
| pa-IV-2 | 由數據形成解釋，並與他人結果互相檢核 |
| pc-IV-1 | 對同學的探究提出有根據的疑問與改善 |
| pc-IV-2 | 用口語、文字、圖表完整表達過程、發現、價值與限制 |
| tc-IV-1 | 對數據與他人報告保持合理懷疑 |
| an-IV-1 | 知道觀察、測量、推論都有限制 |
| ah-IV-1 | 評估推論的證據夠不夠 |
| ai-IV-1／ai-IV-3 | 願意動手做；能與同儕合作探究 |

## 四、學習內容怎麼填（社團課的誠實寫法）

自然領綱的學習內容多是物質、能量、生命、地球等知識起點。科展社團**以探究能力為主軸**，學習內容這樣對：

- **全學期共通**：探究歷程四步（發現問題、規劃與研究、論證與建模、表達與分享）作為知識起點。  
- **能量到測量時**再標 **Ea-IV-1**（時間、長度、質量等基本物理量，可計算密度、體積等衍伸量）。  
- **第 9 週以後**依該組主題補該科學習內容（例如力與運動、溶液、生態取樣），**不要提前寫死**。

跨科概念（可複選）：物質與能量、構造與功能、系統與尺度、改變與穩定、交互作用、科學與生活、資源與永續性。本社團前期以**科學與生活、系統與尺度、改變與穩定**為主。
