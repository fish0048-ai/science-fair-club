# 第 9 週教案｜真實實驗驗證 II 或轉向

> 教師用。研究教練週。請勿印入學生講義。**補 n；模型不符則改假設或縮小。不鎖新實驗食譜。**

| 項目 | 內容 |
| --- | --- |
| 領域／科目 | 自然科學領域（彈性學習／社團） |
| 實施年級 | 國民中學七～九年級 |
| 教學節數 | 共 2 節（120 分鐘），本次為連續第 1–2 節 |
| 單元名稱 | 決定加做、縮小或（少數）轉向備案 |
| 跨科概念 | 各組自訂 |
| 主攻評審面向 | 研究主題（聚焦）；科學方法（數據是否足以支撐） |

---

## 一、設計依據

### （一）學習表現

- **tc-IV-1** 對現有數據合理懷疑：夠不夠下那個結論。
- **pe-IV-1** 規劃「最小加做」或「砍掉次要條件」。
- **po-IV-2** 若題不適合，轉向備案仍須是科學可探究問題。
- **an-IV-1** 接受探究的侷限。

### （二）學習內容

- 論證與建模的決策：不是一直做下去，而是讓問題與證據匹配。
- 學科內容隨各組；教案不新增統一實驗。

### （三）領綱核心素養

- **自-J-A2** 提出可能的解決方案（加做或縮小）。
- **自-J-A3** 依剩餘時間規劃。
- **自-J-C1** 對真實問題做可執行的決定。

### （四）議題融入

- **品德教育**：轉向不是丟臉；編數據才是。
- **生涯規劃**：時間管理。

---

## 二、學習目標

1. 用檢核表判斷：加做／縮小／維持／轉向，四擇一並寫理由。
2. 若加做：只加一個能提高可信度的條件或重複。
3. 若縮小：重寫問題句，使現有數據對得上。
4. 產出核心圖表草稿（可用第 7 週技能）。

---

## 三、學生先備知識

- 兩批次數據或等價資料。幾乎沒有數據者本週以「縮小＋補測」為唯一選項。

## 四、教學活動設計

| 教學活動內容及實施方式 | 時間 | 學習評量 | 備註 |
| --- | --- | --- | --- |
| **引起動機**　三種全國常見死法：題太大、數據太少、結論太滿。 | 0–10 分 | 能對號入座 | |
| **發展活動 1**　教師面談決策（每組約 8 分）。學生先講，教師只准或駁「理由」。 | 10–50 分 | 決策單有簽名 | 不代選題 |

| **綜合活動**　公布後段：分析、說明書／口試、彈性週補數據、發表。作業：核心圖回家補標籤。 | 105–120 分 | 能複述後段產出 | |

## 六、差異化與補救

- 已夠好：本週寫限制與下一步，當全國口試練習。
- 需轉向：用第 3 週備案，承認正式數據週數變少，評量改看「誠實限制」。
- 家長想加設備：擋下，除非不改變操作變因且學生會操作。
